Custom MIT Libraries editor blocks, registered by a single plugin.

== Description ==

Activating this plugin registers the following blocks:

* MITLIB - Hero Section
* MITLIB - Featured and Events Section
* MITLIB - Featured Collection Section
* MITLIB - Using the Libraries Section

These blocks were previously distributed as four separate plugins.

== Installation ==

1. Place the plugin in the `mitlib-blocks` directory of the site plugins folder.
1. Activate the plugin through the 'Plugins' screen in WordPress.
